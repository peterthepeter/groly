# Groly 1.0.0-beta.3

This beta fixes issues found while testing the installed iPhone PWA.

- Items created and immediately checked offline remain checked after reconnecting, including on a second client. Ordered, durable mutations preserve follow-up edits and handle lost responses and overlapping refreshes.
- Shopping favorites are cached per account and available after an offline restart. Offline additions/removals synchronize in order.
- Previously opened recipes remain readable offline. Uncached recipes show a German/English offline message with navigation and retry controls. Cold navigation uses a styled standalone fallback instead of unrelated home-page HTML; redirected login responses are excluded from the document cache.
- PDF font URLs remain valid with root-relative application assets, including export after reconnecting.

Dependencies and database schemas are unchanged from beta.2. Existing IndexedDB data, pending mutations, accounts, sessions and uploads remain compatible. Automatic pre-upgrade snapshots remain enabled. Update using the same data volume and environment settings.

Local verification: 311 tests, zero type errors/warnings, a warning-free production Docker build, Chromium and WebKit offline/PWA-upgrade checks, direct upgrades/restores from 0.9.10, 0.9.9 and 0.9.8-hotfix.2, plus an isolated existing-installation copy. The tested local runtime image has zero reported vulnerabilities across all severities.

The final beta.3 version also passes a direct upgrade, restart and restore from beta.2, preserving all 45 tables and uploaded files.

The release workflow repeats its checks against the actual registry digest before assigning `:1.0.0-beta.3` and `:beta`. Published image verification and digest will be added after completion. The stable `:latest` channel stays on 0.9.10.

Installed-iPhone testing of the corrected offline flows and scheduled reminders/push remains pending before stable.
