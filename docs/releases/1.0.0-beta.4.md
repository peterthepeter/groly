# Groly 1.0.0-beta.4

## Deutsch

- Kontowechsel und Offline-Daten besser geschützt; Anmeldung und Rezeptimport abgesichert; Rezeptansicht und Einkaufsliste verbessert.

## English

- Improved account switching and offline data protection; hardened sign-in and recipe import; improved recipe views and shopping lists.

## Verification

The application changes passed 331 tests, zero type errors/warnings, and all ten Chromium/WebKit browser tests. These include direct upgrades of the published latest PWA, account switching with unsynced changes, offline recipes/favorites, and adding recipe ingredients to shopping lists. Accepted shared recipes remain usable for meal planning and shopping.

Local Docker verification passed fresh installation and direct upgrades from the published latest image (0.9.10), 0.9.10, 0.9.9, and 0.9.8-hotfix.2. Populated fixture data, uploaded images and existing sessions were preserved; restart, backup, restore and safe blocking on backup failure passed. No production database was used for these tests.

The final beta.4 version also passed all ten browser tests and direct upgrade, restart and restore from both the published latest and previous beta images, pinned by immutable digest. See [final-version upgrade evidence](../verification/1.0.0-beta.4-upgrades.json).

The release workflow verifies the final registry image before assigning `:1.0.0-beta.4` and `:beta`. Publication is pending until that workflow succeeds. The stable `:latest` channel stays on 0.9.10.

Installed-iPhone push delivery and a beta check on an actual installation remain pending before stable 1.0. Desktop WebKit does not replace an installed-iPhone test.
