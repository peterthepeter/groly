# Favorite editing – local implementation

2026-10-21. Implemented after explicit user approval; no release published.

Long-press opens the existing item editor for name, quantity and category.
Cancel discards the draft; Save persists it locally. Remove opens the existing
separate confirmation and cancelling that confirmation retains the draft.
Renaming is one durable queued write and one server transaction, preserving
creation time. Already existing shopping items remain unchanged. Duplicate names
are explained without closing the editor. German/English guidance is updated.
No database migration is needed.

Checks already performed: six focused favorite-sync tests passed, including
rename/reload/stale reads. Type-check had zero errors/warnings; production build
passed. Temporary Chromium and WebKit checks covered both layouts/languages,
editing, category selection, cancellation, offline sync, idempotent retry and
removal confirmation. A category-label mismatch in the temporary probe was fixed.
WebKit exposed a delayed selection handler that could append replacement text;
the handler now moves the cursor synchronously, and the WebKit cases passed.
No new browser test suite was added. The existing release offline test was
updated for the editor flow; it has not been rerun against a new Docker image.
