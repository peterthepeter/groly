# Warning cleanup after withdrawal of 1.0.0-beta.1

Date: 2026-10-15. The withdrawn beta is not approved for republication.

## Withdrawal

- GitHub release and Git tag `v1.0.0-beta.1` removed.
- Docker `:beta` restored to its original digest
  `sha256:e199eb54d5b8e7d1b39fe09a30c00660eef571e78650b17499dd7c39450abbaf`
  (0.9.6-beta.3).
- Withdrawn image index, its amd64 manifest and its attestation removed from GHCR.
- Stable `:latest` remains at
  `sha256:29f206017045e27a1b7f41d21b697ed25f6c6c7e7af87228eeca4a0a046756ff`
  (0.9.10).
- Temporary Docker login removed after withdrawal. GitHub package permissions
  were expanded only after explicit user approval and interactive GitHub consent.

## Changes

- Stable Drizzle Kit 0.31.11 retains its executable files unchanged. A reproducible
  [metadata-only vendor patch](../../vendor/README.md) removes its unused abandoned
  esm-loader dependency before installation. The patch is regenerated from a
  SHA-512-verified upstream archive and reproduced byte-for-byte. Generator checks
  use only temporary schema/migration copies: unchanged schema produces no new
  migration; an isolated new table produces only the expected CREATE TABLE.
- Workbox's glob dependency is explicitly resolved to stable 13.0.6. Workbox's
  actual globSync usage, precache generation and existing-worker upgrade are
  exercised by the build/browser gates. There are no forced peer dependencies.
- PWA 2's documented service-worker build integration replaces the deprecated
  inlineDynamicImports setting with Rolldown's codeSplitting=false. Service-worker
  scope, registration, storage and caching rules remain unchanged.
- PDF uses the same pdfmake 0.3.11 browser runtime and all four original Roboto
  faces. The already bundled/minified upstream runtime is a hashed lazy asset;
  fonts are binary TTF assets instead of base64 JavaScript. The vendor runtime
  still has a substantial size; this does not claim to split its opaque UMD code.
  Application chunks are checked below 500,000 bytes; the separate vendor asset
  has an explicit 1,500,000-byte budget. Fonts are checked for valid signatures
  and membership in the service-worker precache.
- PDF data loading still requires the server. A failed export now displays a
  bilingual message and retains the selected options for retry, instead of an
  unhandled promise rejection. InfoModal explains this behavior in both languages.
- Alpine zlib updated to 1.3.2-r1, addressing the medium CVE-2026-85091 finding
  discovered when expanding the image scan to all severities.
- CI explicitly selects ubuntu-26.04. Installed Playwright 1.64.1 contains official
  Ubuntu 26.04 dependency/platform definitions. Local Ubuntu-container validation
  supplements, but does not replace, a real GitHub-hosted runner execution.
- Current actions/cache 6.1.0 caches browser engines. Docker cache export changes
  from mode=max to mode=min with an explicit amd64 scope. Timing improvements
  remain to be measured on GitHub; no release checks were removed.
- npm audit now fails at low severity; image scanning checks all severities.
  Dependency verification rejects deprecated packages and checks vendor integrity.
  The build streams its original diagnostics and fails on emitted warnings;
  warning limits and diagnostic output are not suppressed.

## Remaining release conditions

No new image publication is authorized. A real GitHub Ubuntu 26.04 verification
run and the installed-iPhone PWA/camera/push checks must be reported separately.
Deleting a release cannot remove copies already downloaded by operators. Future
release versioning must account for the withdrawn, previously public beta tag.
