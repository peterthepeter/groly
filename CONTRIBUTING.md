# Contributing to Groly

## Language

Use English for all GitHub-facing content, including:

- README files, documentation, installation guides, and deployment examples.
- Issue and pull request titles, descriptions, and comments.
- Commit messages.
- Release titles/names and release notes, including beta releases.

Do not publish German or bilingual versions of these texts on GitHub. Version-only
release titles such as `v1.0.0` are fine.

Groly itself supports German and English. Keep in-app UI translations and in-app
changelog entries in both languages; GitHub release notes are a separate,
English-only document.
